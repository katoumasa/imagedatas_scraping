# imagedatas_scraping
このスクリプトは、Bingの検索エンジンを用いて指定したスクリプトでの検索結果の画像を自動で保存します。
スクリプトで保存できる枚数はご自身で調整することもできます。

#使用目的
　・指定した検索ワードでの画像スクレイピングにお使いください

#使用用途
　・指定した検索ワードとの関連性（主にSEO対策など）の調査
　・学習用データセットの作成

#全体構成
１.保存先フォルダと検索条件の設定
　保存するフォルダ名と、Bingで検索するための検索ワードを設定できます。
　フォルダ名やプロンプトはご自身の好きなもので構いません。その後の用途に合わせて使いやすいものにしてください。
２.BingImageCrawlerの設定
　Bingでの検索を実施します。
　フィルターを設置しており、画像が大きいもののみにしています（画像学習用に高画質なものであるため）。随時フィルターは変更してお使いください。
　また、画像の取得枚数はmax_numで変更できます。
３.画像ディレクトリの保存
　画像ファイルは先ほど指定したフォルダに自動で保存されます。
４.ディレクトリ内の画像表示
　画像が適切に保存されていることを確認するため、ディレクトリ内の写真がランダムで表示するか聞かれます。
　表示する場合はyを、表示しない場合はzを押してください。

 #注意事項
 　・コードはGoogle colab環境で使用を想定しています。ローカルPCでは使用できません。
   ・エラーが出ますが、エラーが表示されていない他の画像は保存されています。そのため、保存されている画像数は指定した数に満たない場合があります。
   ・取得された画像について研究目的に使ってください。
